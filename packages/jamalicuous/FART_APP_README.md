# 💨 Fart App - The Ultimate Gas Experience

A hilarious and interactive fart app built with Next.js that brings joy and laughter to your day!

## Features

🎯 **Interactive Fart Button**: Click the big yellow button to release the gas!

💨 **Animated Smoke Effects**: Watch beautiful emoji smoke clouds (💨, ☁️, 🌫️, 💭) rise up with realistic animations

🔊 **Sound Effects**: Realistic fart sounds generated using Web Audio API (can be toggled on/off)

📊 **Fart Counter**: Keep track of your gas production with a live counter

🏆 **Achievement System**: 
- Fart Master at 10 farts
- Gas Legend at 50 farts

🎨 **Beautiful Design**: 
- Gradient backgrounds
- Responsive design that works on mobile
- Dark mode support
- Smooth animations and hover effects

📚 **Fun Facts**: Learn interesting fart facts while you play!

## How to Use

1. Click the big "💨 FART! 💨" button
2. Watch the animated smoke clouds rise up
3. Listen to the realistic sound effects (toggle with the sound button)
4. Try to reach achievement milestones
5. Share with friends for maximum laughs!

## Technical Details

- Built with Next.js 15 and React
- Uses Tailwind CSS for styling
- Custom CSS animations for smoke effects
- Web Audio API for sound generation
- TypeScript for type safety
- Responsive design with mobile support
